# QAutoDoc - Word文档内容自动填充工具

QAutoDoc是一款专为Word文档设计的内容自动填充工具，具有格式保持、字段识别和批量处理等核心功能。

## 功能特点

### 1. 文档处理功能
- **格式保持**：在填充内容时完全保留原始Word文档的格式、布局和样式
- **字段识别**：自动识别文档中以 `{{字段名}}` 格式标记的动态字段
- **内容替换**：支持精确替换指定字段内容而不影响文档其他部分

### 2. 用户界面
- **直观操作**：基于PyQt5开发的图形用户界面
- **字段输入面板**：自动为识别到的每个字段创建输入框
- **实时预览**：提供即时预览功能，可查看替换效果

### 3. 批量处理能力
- **多文档生成**：支持根据多组数据一次性生成多个不同的文档
- **智能命名**：自动生成有意义的文件名（基于模板名和字段值）
- **进度显示**：处理过程中显示进度条反馈

### 4. 技术特点
- **依赖库**：基于python-docx库进行Word文档操作，使用PyQt5构建图形界面
- **跨平台**：可在Windows系统上运行（理论上也支持其他平台）
- **易用性**：简单的三步操作流程：打开文档→填写字段→生成结果

## 安装说明

### 系统要求
- Python 3.7+
- Windows 系统（推荐）

### 安装步骤

1. 克隆或下载项目代码
```bash
git clone <repository-url>
cd QAutoDoc
```

2. 安装依赖包
```bash
pip install -r requirements.txt
```

3. 运行程序
```bash
python main.py
```

## 使用方法

### 基本使用流程

1. **打开模板文档**
   - 点击"浏览..."按钮选择Word模板文档（.docx格式）
   - 程序自动识别文档中的 `{{字段名}}` 格式字段

2. **填写字段值**
   - 程序为每个识别到的字段创建输入框
   - 在对应输入框中填写要替换的内容
   - 实时预览区域显示替换效果

3. **生成文档**
   - 点击"生成文档"按钮
   - 选择输出目录
   - 程序自动生成填充后的文档

### 字段标记格式

在Word模板文档中使用以下格式标记动态字段：

```
{{字段名}}
```

**示例：**
```
尊敬的{{姓名}}先生/女士：

感谢您参加{{活动名称}}活动。
活动时间：{{活动时间}}
活动地点：{{活动地点}}
```

### 批量处理

批量处理功能支持一次性处理多组数据：

1. 准备包含多组字段值的CSV文件或数据列表
2. 在批量处理界面导入数据
3. 程序自动为每组数据生成一个文档

## 应用场景

QAutoDoc特别适用于以下场景：

- **批量生成合同**：合同模板中的客户信息、金额、日期等字段自动填充
- **通知书制作**：学生通知书、员工通知书的个性化生成
- **邀请函创建**：活动邀请函的批量制作
- **报告生成**：标准化报告模板的内容填充
- **自动化办公**：减少重复性文档编辑工作

## 技术实现

### 字段识别原理
- 使用正则表达式 `\{\{(.*?)\}\}` 匹配字段标记
- 支持在段落和表格中识别字段
- 保持原始文档格式不变

### 格式保持机制
- 基于python-docx库的底层XML操作
- 精确替换文本内容，保持字体、颜色、大小等样式
- 智能处理段落和运行(run)级别的格式

### 用户界面
- PyQt5框架构建的现代化界面
- 响应式布局设计
- 多线程处理，避免界面卡顿

## 常见问题

### Q: 程序无法识别字段怎么办？
A: 请检查字段格式是否正确，确保使用 `{{字段名}}` 格式，且字段名不包含特殊字符。

### Q: 替换后格式发生变化？
A: 程序会尽力保持原始格式，但某些复杂格式可能需要手动调整。建议先在简单文档上测试。

### Q: 支持哪些Word版本？
A: 支持.docx格式的Word文档（Word 2007及以上版本）。
